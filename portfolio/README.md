# Adarsh S — Portfolio Website

This folder contains the source for Adarsh S's personal portfolio website.

## Structure

- `index.html` — main portfolio page
- `assets/css/style.css` — responsive styling
- `assets/js/main.js` — navigation and small interactions
- `projects/assenttag.html` — AssentTag project detail page
- `projects/epigraphix-ai.html` — EpigraphiX-AI project detail page

The site is designed as a lightweight static portfolio that can be deployed with GitHub Pages.
