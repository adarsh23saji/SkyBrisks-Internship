Privacy-aware image sharing

AssentTag

A privacy-by-default vision application that detects faces and selectively blurs people in shared media, combining biometric verification with a full-stack web workflow.

What it does

  • Detects faces in uploaded media and applies selective Gaussian blurring.
  • Uses ResNet-based 128-dimensional facial embeddings and Euclidean-distance matching for identity verification.
  • Uses a Django + MySQL backend for application logic, authentication and privacy workflows.
  • Provides a responsive web interface with privacy controls, OTP authentication and audit/reporting features.
